          What do these mean? - legend
          

            
added
Exists on the source side of this direction, not the target. In Review client extras this means the client added it.

            
modified
Exists on both sides but differs - a body/parameter/column change.

            
only on other side
Informational: the other side has this, this direction's source doesn't. Never auto-deleted.

            
formatting
Text differs but whitespace/comments/casing-normalized text doesn't - no behavior change.

            
High priority - >5 known callers, or a column was removed/retyped. Review first.

            
Medium priority - other real structural drift.

            
Low priority - formatting-only or documentation-only.

            
AI suggestion
Advisory only, from an LLM reading the diff shown next to it. Never decides, never auto-approves - verify before acting.

Where .bak files are restored for compare and rehearse. Temporary databases are always named drift_* / zz_rehearsal_* and are dropped afterwards.

      

        
These values come from DRIFT_SCRATCH_* environment variables or .env. Edit those to change them.

Drift tool

      
Procedure-body drift between captured .master.sql / .client.sql for the current compare run_id. Lenses transform captured text in memory - they do not re-query SQL Server.

      
Run a .bak SQL Compare first (same picker / run_id). Live scan cannot drive Drift lenses.

      
Live scan mode - Drift lenses are disabled until you run a .bak compare.
